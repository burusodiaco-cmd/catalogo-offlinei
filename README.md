# CatalogoOf

Catálogo Offline Profesional

Desarrollado por Kevin Company.

## Descripción

CatalogoOf es una aplicación Android diseñada para crear y visualizar catálogos de imágenes completamente offline.

## Características

### Visor
- Imágenes a pantalla completa.
- Zoom.
- Deslizar entre imágenes.
- Navegación por categorías.

### Administrador
- Crear categorías.
- Eliminar categorías.
- Agregar imágenes.
- Eliminar imágenes.

### Respaldos
- Crear Backup ZIP.
- Restaurar Backup ZIP.
- Compartir Backup ZIP.

## Diseño

- Tema oscuro.
- Color principal naranja.
- Diseño minimalista.
